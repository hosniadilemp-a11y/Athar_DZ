05 • Open-Source Ecosystem Benchmark & Starter Audit

Audit of 48 Open-Source GitHub Repositories for Criminal & OSINT Investigations

Rather than reinventing 60+ OSINT scrapers or building a graph canvas from zero, we audited the open-source ecosystem to identify the best Starter Frameworks to fork/adapt and the best OSINT & Forensic Tools to wrap as containerized Bricks.

1. Top 5 Starter Platforms: Architectural Audit & What to Reuse

No single existing open-source repository delivers the complete "Photoshop for Criminal Investigations" experience (multi-layer graph + case forensics + deterministic & LLM brick chaining). However, combining architectural patterns from these five flagship repositories gives us 70% of the foundation on Day 1.

Starter #1 jerlendds/osintbuddy

What it is: Open-source visual link-analysis & data-mining platform (Maltego alternative) built with React + Python.

Strengths: Clean Python plugin decorator system where each entity node exposes context-menu transforms on an interactive graph canvas.

Gaps: Lacks multi-layer separation (Verified vs. Raw OSINT vs. Hypothesis), lacks multi-step automated playbooks, and lacks forensic chain-of-custody.

How we use it: Adopt its lightweight Python plugin/entity transform syntax as inspiration for our interactive single-node Brick triggers.

Starter #2 intelowlproject/IntelOwl

What it is: Centralized open-source orchestrator for running 200+ analyzers and external OSINT tools at scale via REST API.

Strengths: Battle-tested Docker + Celery orchestration of heterogeneous CLI tools, API key management, and Playbook grouping.

Gaps: Built primarily for SOC/Malware IOC triage (IPs, hashes, domains) rather than criminal investigations, social media scams, or interactive knowledge graphs.

How we use it: Reuse its containerized Analyzer/Connector runner pattern for our Plane 4 Brick Execution Engine.

Starter #3 blacklanternsecurity/bbot

What it is: Recursive, event-driven OSINT and attack-surface framework in Python (modern successor to SpiderFoot).

Strengths: Brilliant pub/sub event architecture: modules declare `watched_events` (e.g. `URL`, `EMAIL`, `PHONE`) and `produced_events`, chaining automatically across hops.

Gaps: CLI-first red-team tool; no visual investigation studio, no human-in-the-loop per-node review canvas, and no police case management.

How we use it: Model our Non-LLM Deterministic Capability & Chaining Engine directly on BBOT's `watched_events -> produced_events` pub/sub design.

Starter #4 OpenCTI-Platform/opencti & yeti-platform/yeti

What it is: Enterprise graph-backed threat intelligence platforms using STIX 2.1 ontologies and connector workers.

Strengths: Industry-standard relationship modeling, confidence scoring, sighting timestamps, and asynchronous queue-based enrichment connectors.

Gaps: Heavy cybersecurity jargon (Malware, Intrusion Sets) rather than criminal/fraud entities (`MarketplaceAd`, `PhoneNumber`, `CDR`, `Vehicle`, `BankAccount`).

How we use it: Adapt Yeti/OpenCTI's graph relationship provenance model (`confidence`, `first_seen`, `last_seen`, `source_ref`) for our Neo4j schema.

Starter #5 google/timesketch & alephdata/aleph

What it is: Google's collaborative forensic timeline analyzer (`Timesketch`) + OCCRP's investigative document & entity cross-referencing platform (`Aleph` / `FollowTheMoney`).

Strengths: `FollowTheMoney` (`alephdata/followthemoney`) has the best open-source ontology for people, companies, bank accounts, courts, and assets; `Timesketch` excels at chronological correlation.

How we use it: Merge `FollowTheMoney` entity schemas with our SOCMINT/Web ontology and embed a `Timesketch`-style timeline bar beneath the graph canvas.

Our Synthesis AegisInvestigate Studio

Combining the Best of All 5:

  • UI: OSINTBuddy's visual node transforms + Photoshop Layers + Synchronized Timeline & Map.
  • Brain: BBOT's deterministic pub/sub event chaining + Optional LLM Playbook Composer.
  • Runner: IntelOwl's Dockerized analyzer workers + OPSEC Proxy/Sock-Puppet Vault.
  • Ontology: OCCRP FollowTheMoney + STIX 2.1 + Criminal Forensics (CDR, ALPR, DB IDs).
