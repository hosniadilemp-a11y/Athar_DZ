Chapter 03 • Categorized Investigation Tools & Automation

Investigation Tools Menu & How Clues Are Extracted

In AegisInvestigate, every online search technique and forensic analysis utility is packaged as an easy-to-use Investigation Tool. When you select a clue on your Case Board, the app highlights only the tools that actually work with that clue—explaining in plain language what clue you start with, how the tool extracts info step-by-step, and what new clues it discovers.

1. How Automation Works for Investigators (No AI Required vs. With AI)

You never have to guess what tool to use. The platform automatically organizes tools according to your case type and the clues you have collected.

🧭 Standard Mode (Works 100% Without AI)

Strict Investigative Logic:

  • Clue-to-Tool Matching: If you click a Phone Number, only phone tools appear. If you click a Photo, only image forensics and facial comparison tools appear.
  • Safe vs. Active Tools: Completely passive tools (like reading hidden camera dates or looking up telecom operators) run Automatically in the background. Active tools (like checking Instagram or WhatsApp) wait for your 1-click confirmation.
  • Chained Investigation Steps: When Tool 1 discovers a new website link from a post, Tool 2 automatically offers to scan that link for hidden codes and twin scam websites.
🤖 Smart AI Assistant Mode (Optional Copilot)

When You Connect an AI (Local or Cloud):

  • Reads Messy Multilingual Text: Reads Facebook posts and WhatsApp chat screenshots in French, Arabic, or Algerian Darija, picking out hidden phone numbers, payment details, and slang fraud methods.
  • Assembles Custom Investigation Plans: Generates multi-step search pipelines (e.g. "Step 1: Save Post → Step 2: Extract Phone → Step 3: Check Telegram & Marketplace Ads").
  • You Stay in Control: The AI proposes the search sequence with a clear explanation, and you choose whether to Run Step-by-Step or Run Entire Chain.

3. Modular Tool Plug-in Specification (Simple Recipe)

Every tool follows a simple, standardized recipe. Adding a new script or online tool takes less than 15 minutes by writing a simple descriptive configuration file:

Tool Descriptor Recipe (tool.yaml)

# tools/web/hidden_code_finder/tool.yaml
id: "tool.web.hidden_code_finder"
title: "Website Hidden Code & Tracker Extractor"
icon: "🏷️"
category: "WEBSITES_AND_SERVERS"

# Which clues can this tool start from?
starts_from_clues:
  - "Website_Link"
  - "Web_Domain"

# What new clues does this tool discover?
discovers_clues:
  - "Hidden_Order_Code"
  - "Creation_Timestamp"
  - "Ad_Tracker_ID"
  - "Hosting_Server_IP"

# How does it run?
run_settings:
  execution_mode: "AUTOMATIC"   # Safe passive query
  stealth_tier: "RESIDENTIAL_ANONYMOUS_PROXY"
  evidence_snapshot: true      # Automatically freezes the webpage in the Evidence Safe
