3. Step-by-Step Visual Flow: How Services Communicate During an Investigation

Here is what happens behind the scenes in 6 simple steps when an investigator pastes a Facebook Scam Post into a case:

1️⃣ Clue Added on Screen

The investigator pastes the Facebook link or text into the Case Board. The screen sends a secure message (`REST API`) to the Security Gate, which logs the exact time and investigator name.

2️⃣ Automatic Legal Snapshot

Before doing anything else, the Workflow Coordinator (`Temporal.io`) launches the 📸 Page Freezer in an anonymous container to save a permanent screenshot and copy of the post in the Evidence Safe (`MinIO`).

3️⃣ Automatic Clue Extraction

The 🔍 Text Clue Extractor reads the saved post and pulls out the website link (`promo-pneus-express.shop`) and phone number (`+213 555 019 283`), announcing them on the internal event bus (`Redis Streams`).

4️⃣ Live Board Update

The new Phone Number and Website Link cards pop onto the investigator's Case Board live (`WebSockets`) on the 🔎 Online Search Layer, connected by arrows to the original Facebook post.

5️⃣ Smart Next-Tool Suggestions

The Detective Brain immediately checks its rulebook for `Phone Number` and `Website Link`, lighting up friendly badges on those two cards: "4 Phone Tools & 3 Website Tools Ready to Run".

6️⃣ 1-Click or Automatic Pivot

Depending on the investigator's toggle (⚡ Run Automatically vs. ✋ Ask Before Running), the system either runs the safe tools immediately or waits for a single click to uncover the suspect's Telegram, Instagram, and twin scam sites.
